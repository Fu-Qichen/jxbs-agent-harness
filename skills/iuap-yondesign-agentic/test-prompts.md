# Tinper-Agentic 测试提示词

## 1. 经营分析报告页

> 使用tinper-agentic，生成一份季度经营分析报告页面。包含报告标题区（2026年Q1经营分析）、概览摘要（营收同比增长15%，净利润环比下降3%）、核心结论区（增长势头良好但成本端承压）、分析口径说明、关键指标区（营收、净利润、毛利率、经营现金流，需处理正负向趋势色）、证据图表区（营收趋势折线图、成本构成环形图、各业务线对比柱图）、明细与动作区。不需要暗色模式。

## 2. 人力详情资料页

> 使用tinper-agentic，生成一个员工详情资料页面。包含页面标题（员工档案）、概览区（头像、姓名、部门、职级、用工状态标签）、属性区（工号、入职日期、合同到期日、紧急联系人）、指标区（司龄、出勤率、绩效评分、剩余年假）、时间线区（入转调离关键事件）、关联记录区（培训记录、奖惩记录）。

## 3. 报销审批单说明页

> 使用tinper-agentic，生成一个业务单据公共模板示例页面。主题是“招待客户餐费报销审批单”，包含标题区、概览区、基础字段区、结论区（稽核结果）、指标区（金额、票据数、风险数、处理耗时）、明细区（报销明细 / 账单明细 / 费用分摊页签）、流程阶段区、时间线区、图表区（费用构成环形图、节点耗时柱图）、结果摘要区（结算信息）和弹窗详情。要求账号默认脱敏，保留 tabs 与 modal 的通用交互。

## 4. 采购申请单页

> 使用tinper-agentic，生成一个采购申请单页面。包含标题区（研发设备采购申请）、概览区（申请状态、申请人、申请部门、申请金额）、基础字段区（供应商、预算项目、申请日期、用途说明）、明细区（采购清单 / 预算占用 / 审批意见页签）、流程阶段区（提交、部门审批、采买复核、下单完成）、时间线区、结果摘要区和弹窗详情。不需要图表，但保留页签与弹窗交互。

## 5. 请假审批单页

> 使用tinper-agentic，生成一个请假审批单页面。包含标题区（请假审批单）、概览区（申请人、请假类型、当前状态、时长统计）、基础字段区（开始时间、结束时间、代理人、紧急联系方式）、结论区（审批判断）、明细区（请假明细 / 附件记录）、时间线区（审批日志）、结果摘要区（最终安排）和特殊提示区（制度提醒）。不需要图表，不需要进度条。
