# Fast Hit Assembly

## 目标

本文件定义 `yondesign-agentic` 的极速命中和极速拼装逻辑。

## 模板选择

按下面顺序命中，命中即停：

1. 出现 `报告`、`分析`、`问数`、`右侧预览`、`结论`、`图表`：
   命中 `domain-public-report`
2. 出现 `单据`、`审批单`、`申请单`、`报销`、`付款`、`采购`、`合同`、`请假`、`结算`、`发票`、`工单`：
   命中 `domain-public-document`
3. 出现 `详情`、`资料`、`主体`、`档案` 且没有强报告词和强单据词：
   命中 `detail-generic`
4. 无法判断时：
   默认命中 `domain-public-report`

## 区块裁剪

报告极速模式默认只拼：

1. 标题区
2. 概览区
3. 核心结论区
4. 指标区
5. 图表区
6. 明细区
7. 结论建议区

业务单据极速模式默认只拼：

1. 标题区
2. 概览区
3. 基础字段区
4. 明细区
5. 结果摘要区

以下区块默认延后，只有用户明确提到时才补：

- 结论区
- 指标区
- 处理进度区
- 时间线区
- 图表区
- 特殊提示区
- 弹窗详情
